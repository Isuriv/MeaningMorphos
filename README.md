# MeaningMorphos
Selected technology words that have changed meaning between Early Modern English (1500-1700) and Modern English, and future projected semantic change in Martian English (2526). This dataset is to be used with the Meaning Morphos game created for linguistics students to understand the nature of semantic shift over three time periods. 

Meaning ('semantics')
Morphos ('having such a form') - Greek Suffix

To run this game for students, you must insert your own Grok Key in the appropriate region, in the Notebook to set up your own API.
